# 🖥️ برنامج زوهات لويندوز (.exe)

برنامج سطح مكتب حقيقي يفتح النظام بنافذة خاصة **بلا شريط متصفح ولا رابط ظاهر** — يبدو ويتصرّف كأي برنامج ويندوز.

**البيانات تبقى مركزية على الخادم**، فيرى كل الموظفين نفس الشحنات لحظياً تماماً كما هو الحال الآن.

---

## 🔨 كيف تبني الملف التنفيذي؟ (مرة واحدة على جهازك)

### الطريقة السهلة
1. (اختياري لكن مُستحسن) افتح [`zohat_desktop.py`](zohat_desktop.py) وضع رابط شركتك في السطر:
   ```python
   DEFAULT_URL = "https://xxxx.up.railway.app"
   ```
   بهذا يصل البرنامج للموظفين جاهزاً بلا أي إعداد منهم.
2. انقر نقراً مزدوجاً على **`build.bat`**.
3. انتظر دقيقة أو دقيقتين → ستجد الملف في:
   ```
   desktop\dist\Zohat.exe
   ```

### الطريقة اليدوية
```bash
cd desktop
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pyinstaller --noconfirm --onefile --windowed --name "Zohat" --icon icon.ico zohat_desktop.py
```

---

## 📤 كيف ترسله للموظفين؟

أرسل ملف **`Zohat.exe`** فقط (حوالي ١٥–٢٥ ميغابايت) عبر واتساب أو تلغرام أو فلاشة.

- **لا يحتاج تثبيت** — ينقر عليه الموظف مرتين ويعمل مباشرةً.
- يمكنه سحبه إلى سطح المكتب أو تثبيته في شريط المهام.
- عند أول تشغيل: إن لم تضع الرابط قبل البناء، سيطلبه البرنامج **مرة واحدة فقط** ثم يحفظه.

### تغيير الرابط لاحقاً دون إعادة بناء
ضع ملفاً نصياً باسم **`zohat_url.txt`** بجانب `Zohat.exe` يحوي الرابط الجديد فقط — سيقرأه البرنامج تلقائياً.

---

## ✨ ما الذي يميّزه؟

| الميزة | التفاصيل |
|---|---|
| نافذة أصلية | بلا شريط عنوان متصفح — يبدو برنامجاً حقيقياً |
| أيقونة الشركة | لوغو زوهات في سطح المكتب وشريط المهام |
| ملف واحد | لا مجلدات ولا مكتبات مرافقة |
| خفيف | يستخدم محرّك Edge المدمج في ويندوز (لا يحمّل متصفحاً كاملاً) |
| رسائل عربية واضحة | عند انقطاع الإنترنت أو خطأ الرابط، مع زر إعادة محاولة |

---

## ⚠️ متطلبات

- **ويندوز 11**: يعمل مباشرةً (محرّك WebView2 مدمج).
- **ويندوز 10**: قد يحتاج تثبيت [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) مجاناً من مايكروسوفت (مرة واحدة).
- **إنترنت**: مطلوب لأن البيانات مركزية على الخادم.

---

## 🆓 بديل فوري بلا بناء (PWA)

إن أردت حلاً سريعاً الآن: افتح الموقع في **Edge** → أيقونة التثبيت ⊕ في شريط العنوان (أو `⋯` ← Apps ← Install) → سيظهر أيقونة على سطح المكتب تفتح النظام بنافذة مستقلة كالبرنامج تماماً — بلا أي بناء أو إرسال ملفات.
